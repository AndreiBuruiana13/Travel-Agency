# Travel Agency Website

A university Web Technologies project using PHP, HTML, CSS and JavaScript.

## Surviving source

[Travel-Agency-original-files.zip](Travel-Agency-original-files.zip) contains the original `index.php` homepage and an archive note. The homepage presents tourism offers and links to destination details.

Only the homepage survived. Its referenced header/footer includes, styles, scripts, destination pages and contact handlers are missing. This repository is an **incomplete source archive**, not a working or reconstructed application. No new implementation has been added.

Evaluation documents, personal documentation and the supplied stock image are not included in the public archive.
